# Clash 全平台 VPN 使用教程

先来说明，使用 VPN 工具，也就是俗称的**翻墙**或者**梯子**软件。

使用流程分为两部分：
- **VPN 套餐**：需要在提供这类服务的网站购买，大多好用稳定的都是要花钱的
- **VPN 工具（客户端）**：大多是免费的，除了 iOS 之外均可直接下载使用。iOS 下载需要更换 Apple ID 才能下载，在教程中已经有详细的说明

### 手动导入订阅链接

以 **Clash for Android**（手机端）为例，如果一键导入不成功，可以手动操作：

**第一步：复制订阅链接**

1. 回到首页，点击"点我前往教程"旁边的 **"Clash 订阅链接"**
2. 选择下拉列表中的 **"复制 Clash 订阅链接"**

**第二步：导入到客户端**

1. 打开手机上的 **Clash for Android** 软件
2. 在首页点击 **"配置"** 进入配置页面
3. 点击配置页面右上角的 **加号**，导入新的配置
4. 在导入页面选择 **"从 URL 导入"**
5. 在 URL 输入框粘贴复制的链接，点击右上角 **保存**

**第三步：启动代理**

1. 导入成功后回到配置页面，点击刚刚导入的 VPN 套餐配置，使其选中（高亮状态）
2. 回到主页，点击 **"已停止"** 按钮让其变为 **"运行中"**
3. 点击弹出的 **"代理"** 按钮
4. 选择一个节点信息

> [!tip] 节点选择建议
> 推荐选择**新加坡**或**日本**的节点，速度和稳定性通常较好。



### PC端（Linux/Mac/Win）使用 Clash Verge

> [!info] 什么是 Clash Verge？
> [Clash Verge](https://www.clashverge.dev/index.html) 是一款电脑端（Windows / Mac / Linux 都能用）的翻墙客户端软件，界面简洁美观，操作简单，**完全免费**。相比其他翻墙软件，它有这些优点：
>
> - **体积小、不占内存**：软件本身很轻量，不会拖慢电脑
> - **支持更多节点类型**：内置了增强版的代理内核，能兼容各种不同类型的节点
> - **界面好看**：支持深色模式和浅色模式，还可以自定义主题颜色
> - **两种代理模式**：除了常规模式，还支持"虚拟网卡"模式，某些特殊软件也能翻墙
> - **图形化操作**：节点和规则都可以直接在界面上修改，不需要手动编辑代码
> - **配置云同步**：可以把配置备份到云端，换电脑后一键同步，不用重新设置

#### 下载与安装

**下载地址**：[https://www.clashverge.dev/install.html](https://www.clashverge.dev/install.html)

- Windows 用户：不确定的话选 **x64** 版本就行（绝大多数电脑都是这个）
- Mac 用户：新款 MacBook/ iMac 选 **Apple M 芯片**版本，老款 Intel Mac 选 **Intel 芯片**版本
- Windows 7 已不支持，需要升级到 Win10 或 Win11

下载完成后，分别按照每个系统最常见的安装方式进行安装即可。

#### 导入订阅

打开 Clash Verge 后，可以看到这样的首页：

![image.png](https://honlnk-obsidian.honlnk.top/images/20260427_164344_05097c2c4584b080.png)

**第一步：复制订阅链接**

回到 IKUUU 官网，复制订阅链接：
1. 回到首页，点击”点我前往教程”旁边的 **”Clash 订阅链接”**
2. 选择下拉列表中的 **”复制 Clash 订阅链接”**

**第二步：导入到 Clash Verge**

回到 Clash Verge，点击首页的 **”导入”** 按钮，或者点击侧边栏的 **”订阅”** 按钮，进入订阅页面，粘贴刚才复制的链接并确认导入：

![image.png](https://honlnk-obsidian.honlnk.top/images/20260427_164542_771dce49e0b6ae89.png)

#### 代理模式选择

导入成功后，根据自己的使用场景选择代理模式：

- **系统代理**：日常浏览网页、使用普通软件时开启即可
- **虚拟网卡模式**：如果需要使用 Terminal（终端）等命令行工具，必须开启此模式，否则终端内无法翻墙

> [!warning] 注意事项
> - **Mac 用户**：开启虚拟网卡（TUN）模式前，需要先安装依赖。点击页面上 **扳手图标** 即可自动安装
> - **关机前记得关闭系统代理**，或者直接退出 Clash Verge。否则开机后可能会出现无法上网的情况。遇到此问题时，在系统代理开关处执行 **开启 → 关闭 → 再开启** 即可恢复

### HarmonyOS（鸿蒙/华为）安装方式

华为手机的鸿蒙系统分为两个版本，安装方式不同：

#### HarmonyOS NEXT（纯血鸿蒙）

如果你的手机系统版本是 **HarmonyOS 5.0 及以上**（纯血鸿蒙），不再支持安装 Android 应用，需要使用专为鸿蒙开发的客户端：

推荐使用 **ClashBox**（鸿蒙原生应用，GitHub 3.3k Star）：
- **下载地址**：[https://github.com/xiaobaigroup/ClashBox/releases](https://github.com/xiaobaigroup/ClashBox/releases)
- 打开页面后，下载最新版本的安装包，直接安装到手机上（不需要通过华为应用商店）
- 导入订阅链接的方式与 Android 端类似（参考上文的"手动导入订阅链接"步骤）

> [!warning] 安装限制
> - 手动安装的应用**默认只有 14 天有效期**，过期后需要重新安装
> - 开发者完成实名认证后，有效期可延长至 **180 天**
> - 也就是说每隔一段时间可能需要重新下载安装

#### HarmonyOS 2.x / 3.x / 4.x（兼容 Android）

如果你的手机系统版本是 **HarmonyOS 4.0 及以下**，仍然兼容 Android 应用，直接按照前面 **Android 端**的安装方式操作即可（安装 Clash for Android 的 APK 文件）。

> [!tip] 如何查看鸿蒙版本？
> 打开手机 **设置 → 关于手机 → 查看版本号**。如果是 5.0 及以上，就是纯血鸿蒙；4.0 及以下则兼容 Android 应用。
